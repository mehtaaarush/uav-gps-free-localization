Method

  1. Index the map once

    The satellite map is cut into 1,251 overlapping tiles at 160, 224 and 288 px with a 32 px stride, and each tile is embedded with DINOv2 ViT-S/14. The embeddings ship as a 480 KB file.

  2. Retrieve

    The frame is resized to 154 px and embedded by the same network, exported to ONNX with int8 weights and run by ONNX Runtime Web. Cosine similarity picks the eight nearest tiles.

  3. Re-rank and refine

    Each candidate tile is matched to the frame with ORB features and a brute-force Hamming matcher; a RANSAC homography counts inliers and projects the frame centre onto the map. The most inliers wins.

  4. Plan

    A* searches the landmark graph from the fix to the target, with straight-line distance as the heuristic.

The full pipeline in the repository re-ranks with EfficientLoFTR, a dense transformer matcher too heavy for a browser; ORB is its built-in fallback and the one used here. The test frames are crops of the map with simulated drone rotation, tilt, blur and colour shift, so they measure the method, not a real flight. Latitude and longitude come from the map’s corner coordinates.
